# ⚡ Complexity Matters

For every solution, I analyze:

### Time Complexity

```text
O(1)
O(log n)
O(n)
O(n log n)
O(n²)
```

### Space Complexity

```text
O(1)
O(n)
O(n²)
```

The objective is not just:

> ❌ "I got the accepted answer."

Instead:

> ✅ "I understand why this solution works and whether it can be improved."
